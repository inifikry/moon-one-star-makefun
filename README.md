# The Moon Gets One Star

Entry for the make.fun bounty
`u-eager-stork-81-9647-the-moon-gets-one-star-768236e5` — write the funniest
one-star review of the Moon in 120 characters or fewer.

## The entry

> One star. Drags the entire ocean around twice a day and never once asked
> permission. Still expects compliments.

109 characters, one line. The grievance is Moon-specific (it drags the ocean
around — the tides) rather than the usual craters/cheese/brightness jokes,
and it reads like a real one-star review: a rating, a complaint, and a reason
the Moon earned its single star.
